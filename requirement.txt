18 AI Agent Rules

Finally

This is where you control the AI.

Example rules

Never create duplicate components.

Never create duplicate layouts.

Always reuse primitives.

Always check the component library first.

Never hardcode colors.

Never hardcode spacing.

Always use design tokens.

Never create a page without using a page template.

Never introduce a new pattern without approval.

Prefer composition over inheritance.

Prefer reusable components over page-specific implementations.
